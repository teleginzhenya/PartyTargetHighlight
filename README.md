# Party Target Highlight

Highlights your current target on Blizzard’s standard and raid-style party frames and on EllesmereUI party frames in WoW Retail.

Copy the `PartyTargetHighlight` folder into `World of Warcraft/_retail_/Interface/AddOns`. Restart WoW if it is already open, then open the settings with `/pth` or **Settings → AddOns → Party Target Highlight**.

- **Type** defaults to **Dotted border**. Choose **Solid border** for a continuous outline or **Glow** for a soft outline.
- **Color** defaults to yellow. Use **Choose color** to pick any color or enter a hex code.
- **Bold** defaults to **5**. Enter a thickness from **1 to 30** and press Enter to apply.
